# 🏝️ 自立冒險島（Independent Adventure Island）

> **一座專為 15–19 歲青少年設計的 3D 微縮沙盤自立生活模擬遊戲**  
> 結合「嚴肅遊戲（Serious Games）」、「創傷知情設計（Trauma-Informed Design）」與 **CCSA 九大自立生活構念**，讓青少年在零風險的虛擬空間中，透過探索與試錯累積面對現實生活的生存裝備。

🔗 **線上直接試玩**：[https://milkpufftw-arch.github.io/adventure-island/](https://milkpufftw-arch.github.io/adventure-island/)

---

## ✨ 專案特色

* **🎨 療癒系 3D 微縮黏土沙盤**：使用 Three.js 打造的六角蜂巢群島，包含環形低多邊形山脊、漂浮白雲與熱氣球、燈塔與獨木舟衛星小島、動態水波，以及在橋上漫步的 Q 版自立青年小人偶。
* **🎲 38+ 題隨機抽題與選項洗牌**：涵蓋租屋、就業、理財、防詐、求助資源與身心照顧，每次挑戰皆優先抽取未答過的新題並洗牌選項，支援重複練習。
* **🔥 豐富遊戲化機制**：
  * **起跑點抽籤**：開局隨機決定年齡（15–19 歲）與初始存款（$0–$8,000），模擬現實中不同的原生起跑點。
  * **連對 Combo 與成就徽章**：連續答對觸發額外獎金與心情加成，並解鎖 7 枚自立成就徽章。
  * **互動打工與生活小舖**：體驗快速打工（含未成年勞基法保護）、購買營養便當與意外險、建立緊急備用金，以及「BNPL 先買後付」的真實扣款壓力。
  * **9 大生活突發試煉**：演練車手求職陷阱、假交友詐騙、幽靈包裹、警察臨檢、生病與車禍等突發危機。
* **🌿 創傷知情與平靜機制（Calm Technology）**：避免刺耳的失敗懲罰，改以溫和白話的「知識小卡」引導；當心情值過低時，3D 島嶼天空會漸漸起霧，玩家可隨時前往「心・能量花園」進行 **5 秒深呼吸互動** 驅散霧氣。
* **📊 CCSA 九大自立能力雷達圖**：點亮六座小島後，除了獲得象徵自立成功的「豐盛便當」與稱號，系統還會依據決策路徑繪製對應 **CCSA 九大自立構念**（經濟能力、財務管理、自理生活、住所穩定、就業能力、學習能力、關係網絡、問題解決、心理能量）的雷達圖，並附有社工反思引導題。

## 🛠️ 技術架構與隱私保護

* **單一檔案架構（Zero-Backend）**：所有 3D 場景、題庫與雷達圖邏輯皆封裝於單一 `index.html` 中，無需後端伺服器或資料庫即可透過 GitHub Pages 等靜態空間免費運行。
* **核心技術**：HTML5、Tailwind CSS (CDN)、Three.js (`r128` + `OrbitControls`)、Web Audio API（零外部音檔的輕柔療癒音效）、HTML5 Canvas。
* **隱私與社工倫理**：本遊戲**完全在玩家瀏覽器端執行**，不蒐集、不儲存、也不回傳任何個人資料，關閉網頁即重置，符合兒少服務的資安與隱私保護標準。

## 🤝 社工與教育實務應用建議

1. **個案輔導破冰**：邀請青少年遊玩 10–15 分鐘後，透過結局產出的「CCSA 九大能力雷達圖」作為對話媒介，討論他對開局抽籤、求助選擇或詐騙事件的想法。
2. **團體工作坊應用**：可採用「大腦與手」分組模式（一人操作手機、同儕共同討論決策），促進價值觀碰撞與同儕學習。
3. **手機掃碼即玩**：支援手機直式螢幕觸控與底部抽屜介面，建議將試玩網址轉成 QR Code 印於課程簡報或學習單上。

## 📝 如何自行修改題庫？

本專案不需安裝複雜的開發環境即可維護題目：
1. 打開專案中的 `index.html`。
2. 搜尋 `const GAME_DATA =` 區塊。
3. 依照現有 JSON 格式修改或新增 `islands`（各島題庫）與 `randomEvents`（隨機突發事件）中的文字與數值。
4. 儲存並重新上傳（Commit）至 GitHub，等待約 1 分鐘後網頁即會自動更新。
